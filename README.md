# BOTTINA

A Shopify e-commerce website developed for **BOTTINA**, a small business specialising in personalised drinks for events and special occasions.

**Live Website:** Coming soon

## About the Project

BOTTINA creates customised drinks for events and special occasions, allowing customers to order personalised products designed around their event.

This project involves developing and customising a Shopify storefront that provides BOTTINA with an online presence where customers can explore products and place orders.

## My Role

I am responsible for developing and customising the BOTTINA Shopify storefront, including its design, layout, responsive experience and implementation of the business's requirements.

The project is being developed for a real client and will continue to evolve based on feedback and the needs of the business.

## Project Status

**Currently in development**

## What I Learned

BOTTINA is my first project using Shopify, giving me the opportunity to learn a new platform while developing a website for a real business.

Throughout the project, I am developing my understanding of Shopify's theme architecture and customisation while applying my existing web development skills to meet real client requirements.

This project is also giving me experience translating client ideas and feedback into practical website features and design decisions.
